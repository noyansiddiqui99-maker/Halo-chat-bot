## ✦ What is Halo?

**Halo** is a futuristic AI-chat frontend designed to make a chatbot feel more alive, responsive and engaging.

Instead of a traditional static chatbot UI, Halo combines:

- 3D-inspired visual effects
- Animated AI states
- Persistent conversation history
- Interactive message composer
- File attachment UI
- Conversation search
- Rename/delete controls
- Responsive layout
- Local browser storage

> **Current status:** Frontend prototype  
> **AI backend:** Not connected yet  
> **Data storage:** Browser `localStorage`
